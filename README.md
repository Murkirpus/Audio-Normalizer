# Audio Normalizer 🎵

Программа для нормализации громкости аудио и видео файлов с графическим интерфейсом на Python.

![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)

## 📋 Описание

**Audio Normalizer** - это мощный инструмент для пакетной обработки аудио и видео файлов с целью выравнивания их громкости до одного уровня. Программа использует профессиональные алгоритмы нормализации ffmpeg (loudnorm) и предоставляет удобный графический интерфейс для работы.

### Основные возможности

- ✅ **Пакетная обработка** - обработка множества файлов одновременно
- ✅ **Поддержка форматов** - MP3, MP4, WAV, FLAC, AAC, OGG, M4A и другие
- ✅ **Режимы обработки**:
  - Обычная нормализация
  - Музыкальный режим (оптимизирован для музыки)
  - Вокальный режим (с de-esser для вокала)
  - Классика/Опера (сохранение динамического диапазона)
- ✅ **Расширенные настройки**:
  - Noise Gate (удаление тихих шумов)
  - Стерео-расширение
  - 3-полосный эквалайзер (Bass/Mid/Treble)
  - Harmonic Exciter (добавление гармоник)
  - Шумоподавление высоких частот
  - Предотвращение клиппинга
- ✅ **Работа с видео** - нормализация звука в MP4 с сохранением видео
- ✅ **Многопоточность** - использование всех ядер процессора
- ✅ **Прогресс-бар** - отображение процесса обработки

## 🎯 Применение

- Нормализация музыкальной коллекции
- Подготовка аудио для стриминга (YouTube, Spotify)
- Обработка подкастов
- Выравнивание громкости аудиокниг
- Нормализация звука в видеофайлах
- Обработка записей вокала
- Подготовка классической музыки и оперы

   - "Создать" → Добавьте: `C:\ffmpeg\bin`
   - Нажмите "OK" везде

6. Проверьте:
```bash

```

**Вариант 2 (Chocolatey):**
```bash

```

**Вариант 3 (Scoop):**
```bash

```

#### Linux (Ubuntu/Debian)

## 📖 Использование

### Базовый процесс работы

1. **Запустите программу**
2. **Добавьте файлы**:
   - Нажмите "Добавить файлы" и выберите аудио/видео файлы
   - Или "Добавить папку" для обработки всех файлов в папке
3. **Выберите выходную папку** (куда сохранятся обработанные файлы)
4. **Настройте параметры** (опционально)
5. **Нажмите "Нормализовать файлы"**
6. **Дождитесь завершения** (прогресс показывается в окне)

### Настройки программы

#### Целевой уровень громкости (LUFS)
Рекомендуемые значения:
- **-23 dB** - стандарт для ТВ, очень тихо
- **-18 dB** - хорошо для классики и оперы
- **-16 dB** - ⭐ оптимально для большинства музыки
- **-14 dB** - стандарт Spotify, YouTube, громко
- **-12 dB** - очень громко
- **-10 dB** - максимально громко

#### Режимы обработки

**Обычный режим (Normal)**
- Для большинства аудио файлов
- Средний динамический диапазон (LRA=11)
- Умеренная защита от клиппинга

**Музыкальный режим (Music)**
- Специально оптимизирован для музыки
- Сохраняет динамику и басы
- Работает с низкими частотами
- Мягкая компрессия

**Вокальный режим (Vocal)**
- Для записей вокала, подкастов, речи
- Встроенный de-esser (удаление сибилянтов)
- Узкий динамический диапазон (LRA=8)
- Компрессия вокала

**Классика/Опера (Classic/Opera)**
- ⚠️ Сохраняет естественный динамический диапазон
- Очень мягкая обработка
- Широкий LRA=14
- Минимальная компрессия

#### Расширенные настройки

**Noise Gate**
- Включить для удаления фонового шума
- Порог: -50 до -30 dB (чем меньше значение, тем тише шум)
- Рекомендуется: -40 dB

**Стерео-расширение**
- 0 = моно
- 1.0 = исходная стерео база
- 1.5-2.0 = расширенное стерео
- Рекомендуется: 1.2-1.5

**Эквалайзер**
- Bass (40 Hz): ±12 dB
- Mid (1000 Hz): ±12 dB  
- Treble (10000 Hz): ±12 dB

**Harmonic Exciter**
- Добавляет гармоники высоких частот
- Делает звук ярче и прозрачнее

**HF Denoiser**
- Шумоподавление высоких частот
- Полезно для старых записей

**Предотвращение клиппинга**
- Включите для гарантированной защиты от перегрузки
- Немного уменьшает громкость, но избегает искажений

### Работа с видео (MP4)

1. Добавьте MP4 файлы в список
2. ✅ Включите "Сохранить видео в MP4"
3. Программа нормализует звук и сохранит видео без изменений
4. Результат: MP4 с нормализованным звуком

Если галочка выключена - из MP4 будет извлечено только аудио в MP3.

## ⚙️ Технические детали

### Используемые технологии

- **Python 3.8+** - основной язык программирования
- **Tkinter** - графический интерфейс (встроен в Python)
- **FFmpeg** - обработка аудио/видео
- **loudnorm** - алгоритм нормализации громкости (EBU R128)
- **ThreadPoolExecutor** - многопоточная обработка

### Формат нормализации

Программа использует стандарт **EBU R128 (ITU-R BS.1770)** для измерения громкости:
- **I (Integrated Loudness)** - интегральная громкость
- **TP (True Peak)** - истинный пик сигнала
- **LRA (Loudness Range)** - динамический диапазон

### Параметры кодирования

**Аудио (MP3):**
- Кодек: libmp3lame
- Битрейт: 320 kbps (максимальное качество)

**Аудио в видео (AAC):**
- Кодек: AAC
- Битрейт: 192 kbps

**Видео:**
- Копирование без перекодирования (codec copy)

## 🔧 Решение проблем

### Проблема: "ffmpeg не найден"
**Решение:**
1. Убедитесь что FFmpeg установлен: `ffmpeg -version`
2. Проверьте что FFmpeg добавлен в PATH
3. Перезапустите командную строку/терминал
4. Переустановите FFmpeg

### Проблема: "Файл не сохраняется"
**Причины:**
- Слишком экстремальные значения (например, -100 dB)
- Недостаточно прав для записи в выходную папку
- Поврежденный исходный файл
- Нехватка места на диске

**Решение:**
- Используйте нормальные значения (-23 до -10 dB)
- Выберите другую выходную папку
- Проверьте исходный файл в медиа-плеере

### Проблема: Программа зависает
**Решение:**
- Обрабатывайте файлы партиями (по 10-20 штук)
- Закройте другие программы для освобождения памяти
- Проверьте температуру процессора

### Проблема: Искажения звука
**Решение:**
- Включите "Предотвращение клиппинга"
- Уменьшите целевой уровень громкости
- Для классики используйте режим "Classic/Opera"

### Проблема: "No module named 'tkinter'"
**Linux/Ubuntu:**
```bash
sudo apt install python3-tk
```

**macOS:**
```bash
brew install python-tk
```

## 💡 Советы и рекомендации

### Для музыки
- Режим: **Music**
- Целевой уровень: **-16 dB** или **-14 dB**
- Стерео-расширение: **1.2-1.5**
- Включите **Harmonic Exciter** для яркости

### Для подкастов и речи
- Режим: **Vocal**
- Целевой уровень: **-16 dB**
- Включите **Noise Gate** (-40 dB)
- Стерео-расширение: **1.0** (оставьте как есть)

### Для классики и оперы
- Режим: **Classic/Opera**
- Целевой уровень: **-18 dB** или **-20 dB**
- **НЕ включайте** Noise Gate
- Минимум обработки для сохранения динамики

### Для старых записей
- Включите **HF Denoiser**
- Включите **Noise Gate** (-45 dB)
- Используйте **EQ** для коррекции частот

### Для видео
- Обязательно включите "Сохранить видео в MP4"
- Целевой уровень: **-16 dB** (стандарт YouTube)
- Режим: **Music** или **Vocal** в зависимости от контента
